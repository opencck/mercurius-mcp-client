# mercurius-mcp-client

[English](README.md) | **Русский**

Асинхронный клиент Model Context Protocol (MCP) с транспортами stdio и HTTP.

Часть проекта [Меркурий (Mercurius)](https://github.com/opencck/mercurius) — автономного персонального агента. Пакет не зависит от приложения Меркурия и может использоваться отдельно.

**Статус:** код пока в основном репозитории, в [`src/App/Mcp/`](https://github.com/opencck/mercurius/tree/master/src/App/Mcp) (MCP по HTTP, фильтры инструментов, предохранитель, проверка OSV); срока выноса пока нет.

**Стек:** PHP 8.2+, AMPHP v3.
