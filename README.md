# mercurius-mcp-client

**English** | [Русский](README.ru.md)

An asynchronous Model Context Protocol (MCP) client with stdio and HTTP transports.

Part of [Mercurius](https://github.com/opencck/mercurius) — an autonomous personal agent. The package does not depend on the Mercurius application and can be used on its own.

**Status:** the code still lives in the main repository, in [`src/App/Mcp/`](https://github.com/opencck/mercurius/tree/master/src/App/Mcp) (MCP over HTTP, tool filters, a circuit breaker, an OSV check); no date to move it yet.

**Stack:** PHP 8.2+, AMPHP v3.
